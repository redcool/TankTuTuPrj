## 2. 代码规范

### 2.1 架构模式

MVC + ValueObject：

| 层 | 命名空间 | 职责 |
|---|---------|------|
| Controller | `Game.Runtime.Controller` | 游戏逻辑、Manager、Spawner |
| View | `Game.Runtime.UI` | UI Presenter、界面逻辑 |
| ValueObject | `Game.Runtime.ValueObject` | 纯数据类、ScriptableObject |

### 2.2 文件命名

- **全部 PascalCase**：`PlayerController.cs`、`TankDataValue.cs`
- 脚本文件名必须与类名完全一致
- SO 文件名：`{Category}_{SubCategory}_{Name}.asset`
  - 武器：`Weapon_MainCannon_HeavyCannon.asset`
  - 角色：`Character_HeavyTank.asset`

### 2.3 脚本结构

```csharp
namespace Game.Runtime.Controller
{
    public class PlayerController : MonoBehaviour
    {
        // 1. Constants
        private const float MAX_SPEED = 10f;
        // 2. SerializeField
        [SerializeField] private float _moveSpeed = 5f;
        // 3. Private fields
        private Rigidbody2D _rb;
        // 4. Public properties
        public int CurrentHp { get; private set; }
        // 5. Lifecycle (Awake → Start → Update → FixedUpdate)
        private void Awake() { }
        private void Start() { }
        private void Update() { }
        // 6. Public methods
        public void TakeDamage(int damage) { }
        // 7. Private methods
        private void MovePlayer() { }
    }
}
```

### 2.4 字体规范

- 标题/数字：Rajdhani（科技感、紧凑）
- 正文：JyunsaiKaai-Regular SDF（日式手写感）
- **Unity USS 中必须使用 `-unity-font-definition`** 引用 SDF 字体资产
- 禁止使用 `font-family`（Unity USS 不支持 CSS 字体栈）
- 禁止使用 `-unity-font: var(--font-xxx)`（Unity 不支持 css 变量在字体属性中）

正确写法：
```css
-unity-font-definition: url("project://database/Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset");
```

### 2.5 SO Icon 字段

WeaponDataSO 和 CharacterDataSO 皆有 `Sprite _icon` 字段。如果 SO 中未赋值，由 Presenter 从文件路径加载：

```csharp
// Presenter 中加载图标
var iconPath = Path.Combine(
    Application.dataPath.Replace("/Assets", ""),
    "Assets", "Arts", "UI", "WeaponIcons",
    $"{iconName}.png"
);
if (File.Exists(iconPath))
{
    var tex = new Texture2D(2, 2);
    tex.LoadImage(File.ReadAllBytes(iconPath));
    iconImage.image = tex;
}
```

图标文件名从 SO asset name 推导：
- `Weapon_MainCannon_LightCannon` → `LightCannon.png`
- `Character_HeavyTank` → `HeavyTank.png`

## 5. ComfyUI 资源生成流程

### 5.1 模型配置

| 组件 | 文件 | 节点 | 参数 |
|------|------|------|------|
| UNET | `z_image_turbo_bf16.safetensors` | UNETLoader | weight_dtype: default |
| CLIP | `qwen_3_4b.safetensors` | CLIPLoader | type: qwen_image |
| VAE | `ae.safetensors` | VAELoader | - |

### 5.2 生成参数

| 参数 | 值 |
|------|-----|
| 尺寸 | 1024×1024 |
| 步数 | 4 |
| CFG | 2.5 |
| 采样器 | euler |
| 调度器 | simple |
| 文本编码 | TextEncodeZImageOmni × 2（正 + 负） |

### 5.3 Prompt 规范

- **武器图标：中文 prompt**，详细描述材质、颜色、结构细节
- **角色头像：英文 prompt**，描述车辆特征、涂装
- 风格关键词追加在 prompt 末尾：`realistic, high fidelity, detailed texture, PBR, game asset`
- 详细的 weapon prompt 保存到 `docs/weaponIconsPrompt.md`，每把武器一行，标注 seed

### 5.4 标准工作流

```
1. 编写 prompt → 保存到对应 category 目录下的 prompt.txt 和 docs 中的 .md 文件
2. 分配唯一种子（见种子分配规则）
3. 通过 ComfyUI API 批量生成
   POST http://localhost:8188/prompt
4. 监控队列直到完成
   GET http://localhost:8188/queue
5. 从 ComfyUI\output 复制 PNG 到 Assets/Arts/UI/{Category}/
6. 更新 meta.json 中的 records
```

### 5.5 批量生成脚本模板（PowerShell）

```powershell
function New-Workflow($prefix, $pos, $neg, $seed) {
    $wf = @{}
    $wf["1"] = @{ class_type="UNETLoader"; inputs=@{ unet_name="z_image_turbo_bf16.safetensors"; weight_dtype="default" } }
    $wf["2"] = @{ class_type="CLIPLoader"; inputs=@{ clip_name="qwen_3_4b.safetensors"; type="qwen_image" } }
    $wf["3"] = @{ class_type="VAELoader"; inputs=@{ vae_name="ae.safetensors" } }
    $wf["4"] = @{ class_type="EmptyLatentImage"; inputs=@{ width=1024; height=1024; batch_size=1 } }
    $wf["5"] = @{ class_type="TextEncodeZImageOmni"; inputs=@{ clip=@("2",0); prompt=$pos; auto_resize_images=$true } }
    $wf["6"] = @{ class_type="TextEncodeZImageOmni"; inputs=@{ clip=@("2",0); prompt=$neg; auto_resize_images=$true } }
    $wf["7"] = @{ class_type="KSampler"; inputs=@{ seed=$seed; steps=4; cfg=2.5; sampler_name="euler"; scheduler="simple"; denoise=1.0; model=@("1",0); positive=@("5",0); negative=@("6",0); latent_image=@("4",0) } }
    $wf["8"] = @{ class_type="VAEDecode"; inputs=@{ samples=@("7",0); vae=@("3",0) } }
    $wf["9"] = @{ class_type="SaveImage"; inputs=@{ filename_prefix=$prefix; images=@("8",0) } }
    return $wf
}
```

