# 字体设置

## 默认中文字体

| 项目 | 值 |
|------|-----|
| 字体名称 | JyunsaiKaai-Regular |
| SDF Asset | `Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset` |
| 源文件 | `Assets/Arts/Fonts/JyunsaiKaai-Regular.ttf` (需自行安装) |
| SDF 模式 | TMP Font Asset Creator 生成 |
| 使用场景 | UI Toolkit 全局中文字体 |

## 在 USS 中引用

```css
/* 在主 USS (Common.uss) 中设置全局默认字体 */
* {
    -unity-font-definition: url("project://database/Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset");
}
```

或在单个元素上指定：

```css
.menu-title {
    -unity-font-definition: url("project://database/Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset");
    font-size: 64px;
}
```

**注意**: Unity UI Toolkit USS 中 `-unity-font-definition` 引用的是 `.asset` 文件（TMP Font Asset），不是 `.ttf` 源文件。

## 生成说明

使用 TMP Font Asset Creator 生成：
- Window → TextMeshPro → Font Asset Creator
- Source Font: JyunsaiKaai-Regular.ttf
- Render Mode: SDF
- Atlas Resolution: 建议 1024×2048（支持完整中文）
- Character Set: 建议 ASCII + 常用中文（或 Unicode Range 支持全中文）
- 生成后保存到 `Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset`

## 文件清单

| 文件 | 说明 |
|------|------|
| `Assets/Arts/Fonts/JyunsaiKaai-Regular SDF.asset` | SDF 字体资源（主用） |

| `Assets/Arts/Fonts/JyunsaiKaai-Regular.ttf` | 原始 TTF 字体文件 |
