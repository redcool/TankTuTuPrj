# 武器设计文档 — 铁皮突突 (TankTuTu)

> 版本: v1.0 | 最后更新: 2026-05-22
> 设计目标: 18种武器 × 6大类别，差异化射击体验

---

## 一、设计理念

### 1.1 核心原则

- **武器即Build**：每把武器决定玩家的打法风格，而非单纯数值堆叠
- **6武器槽位**：战车最多装备6把武器，独立冷却、独立射击
- **自动瞄准**：武器自动锁定范围内最近敌人，玩家专注走位
- **稀有度阶梯**：Common → Rare → Epic → Legendary，影响基础属性和特殊效果
- **升级系统**：相同武器可以合并升级，提升伤害和攻速
- **类别协同**：战车属性（远程/近战/元素/工程）对不同类别武器有加成

### 1.2 武器类别

```csharp
MainCannon  — 主炮类  → 受 RangedDamage 加成   → 单发高伤、精准
MachineGun  — 机枪类  → 受 Ranged+Melee 折中   → 高速连射、弹幕
Missile     — 导弹类  → 受 ElementDamage 加成   → 高爆发、追踪
Sprayer     — 喷射类  → 受 ElementDamage+Engineering 加成 → 持续伤害、范围
Melee       — 近战类  → 受 MeleeDamage 加成     → 高风险、高回报
```

### 4.2 基准值设定

```
DPS基准线（白板）: ~30
DPS范围: 20 ~ 120

价格基准:
  - Common:  80 ~ 200   (DPS 30~35)
  - Rare:    200 ~ 350  (DPS 35~60)
  - Epic:    350 ~ 450  (DPS 60~80 含特性)
  - Legendary: 500+     (DPS 100+ 含强力特性)
```

### 4.3 升级曲线

相同武器合并升级：
```
Lv1 → Lv2: 伤害×1.15, 攻速×1.05, 费用×2
Lv2 → Lv3: 伤害×1.15, 攻速×1.05, 费用×2
Lv3 → Lv4: 伤害×1.15, 攻速×1.05, 费用×2
Lv4 → Lv5: 伤害×1.15, 攻速×1.05, 费用×2 (Max)

最终 Lv5: 伤害×1.75, 攻速×1.22 (相对Lv1)
```
