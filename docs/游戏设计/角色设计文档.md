# 角色设计文档 — 铁皮突突 (TankTuTu)

> 版本: v1.0 | 最后更新: 2026-05-22
> 设计目标: 类 Brotato 俯视角射击，战车角色差异化设计

---

## 一、设计理念

### 1.1 核心原则

- **角色即车**：每个角色是一辆战车，而非人物。角色差异化体现在车辆类型、属性和特殊能力上。
- **Brotato-like 属性修正**：每个角色拥有基础属性 + 正负修正，鼓励玩家围绕角色特点构筑 Build。
- **配合武器系统**：角色的属性偏向决定其适配的武器类型，形成"角色-武器"协同。
- **解锁驱动**：通过游戏行为解锁新角色，保持新鲜感。

### 1.2 VehicleType 分类

```csharp
TANK    — 主战/重型坦克   — 正面作战，高生存
LIGHT   — 轻型/侦察车     — 高速机动，游击战术
APC     — 运兵/工程支援车  — 均衡/辅助，资源运营
SPG     — 自行火炮/高炮    — 远程输出/弹幕压制
SPECIAL — 特种车辆         — 独特机制，非常规玩法
```

### 3.1 主战坦克 (mbt)

> _"坚不可摧的移动堡垒"_

| 属性 | 基值 | 修正 | 最终 |
|------|------|------|------|
| 最大生命 | 180 | — | **180** |
| 移速 | 2.2 | — | **2.2** |
| 攻速 | 0.7 | — | **0.7** |
| 护甲 | 5 | — | **5** |
| 闪避 | 5% | — | **5%** |
| 范围 | 10 | — | **10** |
| 暴击率 | 5% | — | **5%** |
| 生命窃取 | — | — | **0%** |
| 收获 | 1.0 | — | **1.0** |

**特殊能力：能量护盾**
- 每30秒生成一个护盾，吸收100点伤害
- 护盾持续至被击破或30秒刷新
- 护盾存在期间免疫击退

**初始武器**：`Weapon_MainCannon_StandardCannon`（标准加农炮）

**设计意图**：
- 典型的"坦克"角色。高HP+高护甲+护盾 = 最硬的角色
- 代价是低移速中攻速，缺乏爆发
- 适合新手和喜欢站撸的玩家
- 配合护甲穿透/生命窃取类武器效果好

**解锁条件**：默认解锁

## 七、平衡性总结

### 生存三角

```
高HP+高护甲 ────────── 低移速
  (MBT, Engineer)    (SPG, MBT)
       │                    │
       │    均衡 ─── 中HP   │
       │    (IFV, APC)      │
       │                    │
高移速+高闪避 ────────── 低HP
  (Jeep, Scout)      (Jeep, TD, SPG)
```

### 输出风格光谱

```
单发高伤 ─────────────────── 多发射速
TD, SPG                        AA, Scout
    │                            │
    │     ── Cannon (均衡) ──    │
    │     ── Missile (爆发) ──   │
    │     ── Flame (持续) ────   │
```

### 经济效率

```
高收获: APC (2.0) > Jeep (1.3) > Scout (1.2) > IFV (1.1) > ...
高幸运: APC (15) > Jeep (10) > TD (0) > ...
```
