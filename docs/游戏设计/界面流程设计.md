# 界面流程设计文档 — 坦克突突 (TankTuTu)

> 版本: v1.0 | 最后更新: 2026-05-23
> 引擎: Unity 2022.3 + UI Toolkit (UIDocument)

---

## 一、流程总览

```
主界面 ──→ 角色选择 ──→ 武器选择 ──→ 难度选择 ──→ 开始战斗
(StartMenu)  (CharacterSelect)  (WeaponSelect)  (DifficultySelect)  (Level_0)
```

### 1.1 导航规则

- **前进**: 每个界面点击**确认**按钮进入下一步
- **返回**: 每个界面左上角有 **← 返回** 按钮，按导航栈返回上一级
- **中断**: 任意时刻可通过右上角设置/退出关闭游戏

### 1.2 数据流

```
StartMenu
  │  [无数据传递]
  ▼
CharacterSelect
  │  → GameManager.SelectedCharacterId (string)
  │  → GameManager.SelectedCharacterData (CharacterDataSO)
  ▼
WeaponSelect
  │  → GameManager.SelectedWeaponId (string)
  │  → GameManager.SelectedWeaponData (WeaponDataSO)
  ▼
DifficultySelect
  │  → GameManager.SelectedDifficultyLevel (int)
  │  → GameManager.SelectedDifficultyData (DifficultyDataSO)
  ▼
Battle (Level_0.scene)
  │  TankController 读取 GameManager 数据初始化角色
  │  LevelManager 根据难度数据配置刷怪参数
```

## 二、界面详细设计

### 2.1 主界面 (StartMenu)

**功能**: 游戏入口，提供继续/新游戏/设置/退出

**UXML Panel**: `panel-start-menu`
**Presenter**: `StartMenuPresenter.cs`
**USS**: `StartMenu.uss`, `Common.uss`

**元素**:

| 名称 | 类型 | 用途 |
|------|------|------|
| `btn-continue` | Button | 继续上次战斗（有存档时显示） |
| `continue-separator` | VisualElement | 分隔线（有存档时显示） |
| `btn-new-game` | Button | 新游戏 → 进入角色选择 |
| `btn-settings` | Button | 设置 |
| `btn-quit` | Button | 退出游戏 |
| `menu-title` | Label | "坦克突突" 标题 |
| `menu-subtitle` | Label | "TANK TUTU" 副标题 |

**行为**:
- 新游戏 → `UIFlowManager.GoToCharacterSelect()`
- 继续 → `UIFlowManager.GoToDifficultySelect()`（跳过角色/武器）
- 设置 → `UIFlowManager.GoToSettings()`
- 退出 → `Application.Quit()`

## 三、技术实现

### 3.1 UI 架构

```
UIDocument (场景中)
  └── MainRoot.uxml (根 UXML)
       ├── panel-start-menu (主菜单)
       ├── panel-character-select (角色选择)
       ├── panel-weapon-select (武器选择)
       ├── panel-difficulty-select (难度选择)
       └── panel-battle-hud (战斗 HUD, 预留给战斗场景)
```

所有面板在同一个 UIDocument 中，通过 `UIFlowManager.Show(UIState)` 切换显示/隐藏。

### 3.2 Presenter 生命周期

```
Awake/Start → 获取 UIFlowManager.Instance
           → 调用 _flow.Initialize()（绑定 UIDocument）
           → 查询 UI 元素（_root.Q<>()）
           → 注册事件回调
           → 加载数据（Resources.LoadAll）
           → 构建界面（CreateCard 等）

OnDestroy → 注销事件回调
```

### 3.3 跨场景数据传递

使用 `GameManager`（单例，DontDestroyOnLoad）：

```csharp
// 角色选择 - 写入
GameManager.Instance.SelectedCharacterId = character.CharacterId;
GameManager.Instance.SelectedCharacterData = character;

// 武器选择 - 写入
GameManager.Instance.SelectedWeaponId = weapon.WeaponId;
GameManager.Instance.SelectedWeaponData = weapon;

// 难度选择 - 写入
GameManager.Instance.SelectedDifficultyData = difficulty;

// 战斗场景 - 读取
var charData = GameManager.Instance.SelectedCharacterData;
var weaponData = GameManager.Instance.SelectedWeaponData;
var diffData = GameManager.Instance.SelectedDifficultyData;
```

### 3.4 USS 文件结构

```
Assets/UI/
├── Common/Common.uss          → 全局样式（颜色/字体/按钮/布局）
├── StartMenu/StartMenu.uss    → 主菜单专属样式
├── CharacterSelect/
│   ├── CharacterSelect.uss    → 角色选择布局样式
│   └── CharacterCard.uss      → 角色卡片样式
├── WeaponSelect/
│   ├── WeaponSelect.uss       → 武器选择布局样式
│   └── WeaponCard.uss         → 武器卡片样式
├── DifficultySelect/
│   └── DifficultySelect.uss   → 难度选择样式
└── BattleHUD/
    └── BattleHud.uss          → 战斗 HUD 样式
```
