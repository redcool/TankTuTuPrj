# 游戏角色与武器道具生成规则

## 1. 数据流

```
主界面 → 角色选择 → 武器选择 → 难度选择 → 开始战斗
                                            ↓
                                    GameManager 存储全部选择
                                            ↓
                                    SceneManager.LoadScene("Level_0")
                                            ↓
                                    SceneInitializer 激活 PlayerTank
                                            ↓
                                    TankController 读取 GameManager 数据
                                            ↓
                                    动态加载 kenney_car 模型 + 生成武器槽
```

## 2. GameManager 数据载体

### 现有字段
```
SelectedCharacterId    string          — 角色 ID（如 "mbt"）
SelectedCharacterData CharacterDataSO — 角色数据
SelectedWeaponId       string          — 武器 ID
SelectedWeaponData     WeaponDataSO    — 武器数据
SelectedDifficultyLevel int            — 难度等级
SelectedDifficultyData DifficultyDataSO — 难度数据
```

### 扩展：多武器支持
```
SelectedWeaponDatas    List<WeaponDataSO> — 已选择的武器列表
SelectedWeaponPrefabPaths List<string>    — 武器预制体路径列表（运行时加载）
```

## 4. 武器 → 模型映射

### 现有预制体
- `Assets/Resources/Prefabs/Weapons/blaster-a.prefab`
- `Assets/Resources/Prefabs/Weapons/blaster-b.prefab`
- `Assets/Resources/Prefabs/Weapons/blaster-d.prefab`
- `Assets/Resources/Prefabs/Weapons/scope-large-a.prefab`

### 可用 kenney_blaster FBX 列表
blaster-a ~ blaster-r + scope-large-a/b, scope-small, silencer-small/larger 等

### 映射规则
根据 `WeaponDataSO.WeaponCategory` 选择：

| 武器类别 | 使用模型 |
|---------|---------|
| MainCannon (主炮) | blaster-d (重型) |
| MachineGun (机枪) | blaster-a (小型速射) |
| Missile (导弹) | blaster-b (中型) |
| Sprayer (喷射) | scope-large-a (宽口) |
| Melee (近战) | blaster-c (短管) |

在 `WeaponModelMapper` 中定义，后续可根据预制体资源完善。

## 5. 武器槽位生成规则

### 动态生成
TankController 启动时，根据 `SelectedWeaponDatas.Count` 动态生成武器槽位。

### 360° 环绕布局
以战车本地原点为圆心，按武器数量等分 360°：

```
武器数量 | 角度分布
1        | 0°（正前方）
2        | 0°, 180°
3        | 0°, 120°, 240°
4        | 0°, 90°, 180°, 270°
5        | 0°, 72°, 144°, 216°, 288°
6        | 0°, 60°, 120°, 180°, 240°, 300°
```

**实现**：生成空 GameObject 作为 slot，定位到圆上坐标：
```
radius = 1.5 单位（战车大小的一半 + 武器伸出距离）
x = radius * sin(angle)
z = radius * cos(angle)
y = 1.0（离地高度）
```

每个 slot 挂载 `WeaponSlot` 组件，安装对应武器预制体。

### 槽位结构
```
PlayerTank
├── Model_Container
│   └── [kenney_car model]          ← 动态加载
├── DynamicWeaponSlots              ← 动态创建
│   ├── WeaponSlot_0 (0°)
│   ├── WeaponSlot_1 (60°)
│   ├── ...
│   └── WeaponSlot_N
```

## 6. 场景初始化流程

`Level_0.unity` 场景已经预置了 PlayerTank（inactive）。

**SceneInitializer.Start()** 扩展：
```
1. 查找场景中的 PlayerTank（inactive）
2. 设置 GameManager 的武器列表数据
3. 激活 PlayerTank → TankController.Awake() 运行
4. TankController 从 GameManager 读取角色数据
5. 根据角色 ID 加载对应的 kenney_car 模型到 Model_Container
6. 读取 SelectedWeaponDatas，按 360° 生成武器槽
7. 为每个槽加载武器预制体（从 kenney_blaster 模型）
8. 原有初始化（EnemySpawner、LevelManager）不变
```

## 7. TankController 修改点

### InstantiateTank() 方法
- **原行为**：加载 `_tankPrefab` 硬编码引用
- **新行为**：根据 `GameManager.SelectedCharacterData.CharacterId` 从 `CharacterModelMapper` 获取模型名称 → 从 `Assets/Arts/kenney_car/{modelName}.fbx` 加载 → 实例化到 `Model_Container`

### 新增：CreateWeaponSlots() 方法
- 读取 `GameManager.SelectedWeaponDatas`
- 按 360° 分布生成 slot
- 为每个 slot 挂载 WeaponSlot 组件
- 通过 `WeaponModelMapper` 获取对应模型 → 实例化到 slot
- 调用 `slot.InstallWeapon(data, prefab)`

### 新增：CreateDefaultWeapon() 方法
- 当没有选择武器时（或仅防御性武器），生成一个默认机关炮

## 8. 资源加载路径

所有模型通过 Resources API 动态加载：

```csharp
// 车辆模型
Resources.Load<GameObject>("Arts/kenney_car/" + modelName);

// 武器预制体（已有 WeaponSlot 组件等）
Resources.Load<GameObject>("Prefabs/Weapons/" + weaponPrefabName);

// 如果 kenney_car 模型没有预制体，从 FBX 动态加载
// 可能需要在 Assets/Resources 下创建对应预制体引用
```

## 9. 现有架构兼容性

| 系统 | 是否修改 | 原因 |
|------|---------|------|
| GameManager | 是 | 添加多武器列表字段 |
| TankController | 是 | 动态模型加载、武器槽创建 |
| SceneInitializer | 是 | 激活 PlayerTank |
| WeaponSelectPresenter | 否 | 现有单武器选择 OK（后续改为多槽） |
| MultiplayerManager | 否 | 后期扩展 |
| PlayerTank.prefab | 否 | 作为容器模板，模型动态加载 |
| Level_0.unity | 否 | 已有 PlayerTank 引用 |
