# 坦克突突 — 美术风格指南

## 1. 整体风格

**写实风格（Realistic / PBR）**

以军事拟真为基调，强调材质细节、光影真实感和 PBR 质感。

核心关键词：
```
高保真（high fidelity）  |  材质细节（detailed texture）
PBR 渲染               |  光影真实（realistic lighting）
军事拟真（military accurate） |  游戏资产（game-ready）
```

## 3. 角色 — 车辆头像

### 3.1 总体要求

- **俯视角度**（top-down view）
- 1024×1024 PNG，白色背景
- 精细欧美卡通风格：适当增加细节层次、高光阴影、材质肌理
- 每辆车有明确的迷彩/配色方案

| 自行火炮 | 橄榄褐 | 长炮管、敞开式战斗室 |

## 4. 武器图标

### 4.1 总体要求

- **俯视角度**（top-down view）
- 1024×1024 PNG，白色背景
- 精细欧美卡通风格
- 武器独立展示，无手持角色
- 保留"可拾取"的地面物品感

### 4.2 五大类 18 种

**主炮类** — 炮管为主视觉，强调口径感
```
轻型火炮   | 细长炮管
标准火炮   | 均衡炮管
重型火炮   | 粗短炮管、炮口制退器
速射炮     | 多根小口径炮管
攻城炮     | 巨大炮身、加固底座
```

**机枪类** — 强调枪管数量和供弹方式
```
轻机枪     | 两脚架、弹链
重机枪     | 三脚架、大口径
加特林     | 旋转多管、电动
电磁机枪   | 线圈结构、能量发光
```

**导弹类** — 发射器为主
```
反坦克导弹 | 筒状发射器
火箭弹     | 多管火箭炮
制导导弹   | 弹翼+导引头
```

**喷射类** — 喷头+储罐
```
火焰喷射器 | 喷嘴+燃料罐、燃烧效果
冷冻喷射器 | 冰霜质感喷嘴
高压水炮   | 消防水炮造型
酸液喷射器 | 绿色化学罐
```

**近战类** — 机械感
```
钻头       | 螺旋钻尖、电机
链锯       | 锯齿链条、导板
```

```

```

## 6. 场景/关卡

### 6.1 俯视视角

游戏为俯视角 3D 射击，场景风格要点：

| 要素 | 风格要求 |
|------|---------|
| 地形 | 平坦为主，适当障碍物，色彩明亮饱和 |
| 建筑/掩体 | 军事设施、仓库、掩体墙，卡通化比例（门窗偏大） |
| 道路 | 沥青/土路，清晰引导线 |
| 植被 | 卡通风格树木/灌木，非写实 |
| 特效（爆炸、烟雾） | 色彩鲜艳、轮廓清晰、不遮挡视野 |

### 6.2 材质风格

- 车辆使用全色（flat color）+ 简单高光，类似卡通渲染（toon shading）
- 不使用 PBR 写实质感
- 阴影：硬阴影（hard shadow），轮廓分明
- 轮廓线：可选的黑色外轮廓描边

## 7. UI 界面

### 7.1 整体调性

军事极简风：深色基调 + 军绿色强调

```
背景:    #0d0d0d ~ #222222   （深色渐变）
卡片:    #2a2a2a              （可交互面板）
边框:    #3a3a3a              （默认）/ #4a7c3f（选中）
强调色:  #4a7c3f 军绿        （按钮/选中/进度）
点缀色:  #c8a84e 军铜        （特殊/稀有/金色物品）
```

### 7.2 字体

| 用途 | 字体 | 备注 |
|------|------|------|
| 标题/数字 | Rajdhani | 科技感、紧凑、适合 HUD 数值 |
| 正文 | JyunsaiKaai-Regular SDF | 日式手写感、搭配军事主题 |
| 代码/小字 | Rajdhani | 版本号等 |

在 USS 中使用 `-unity-font-definition` 引用 SDF 字体资产。

### 7.3 ICON 引用

```
<Image class="weapon-icon" background-image="Assets/Arts/UI/WeaponIcons/HeavyCannon.png" />
<Image class="character-portrait" background-image="Assets/Arts/UI/CharacterPortraits/HeavyTank.png" />
```

路径约定：`Assets/Arts/UI/{Category}/{PascalCase}.png`

### 7.4 布局风格

- 圆角矩形面板（radius: 4-12px）
- 卡片式列表（hover 高亮 #333，选中军绿边框）
- 大间距呼吸感（spacing: 8-32px）
- 半透明选中遮罩（rgba 军绿）

## 8. 生成管线

所有 2D ICON 资源通过 ComfyUI z_image_turbo 生成：

```
模型:    z_image_turbo_bf16.safetensors
CLIP:    qwen_3_4b.safetensors (qwen_image)
VAE:     ae.safetensors
尺寸:    1024×1024
步数:    4 | CFG: 2.5
采样器:  euler | 调度器: simple
文本编码: TextEncodeZImageOmni × 2 (正 + 负)
```

详细工作流见 `docs/ComfyUI_2D生成工作流.md`。
