## 新增需求

### 需求:战车控制系统
游戏必须支持战车移动控制，使用摇杆控制方向，战车自动朝向移动方向。

#### 场景:战车移动
- **当** 玩家推动左摇杆
- **那么** 战车向摇杆方向移动，移动速度由moveSpeed属性决定

#### 场景:战车转向
- **当** 战车移动时
- **那么** 战车自动旋转朝向移动方向

### 需求:战车数值属性
战车必须拥有15种数值属性，影响游戏体验。

#### 场景:最大生命值
- **当** 战车受到伤害
- **那么** 当前生命值减少，减少量 = 原始伤害 - 护甲减免（护甲减少 min(伤害, 护甲值) 点伤害）

#### 场景:生命回复
- **当** 战车生命值不满且生命回复 > 0
- **那么** 每秒恢复生命回复值的生命

#### 场景:生命窃取
- **当** 战车攻击造成伤害
- **那么** 恢复 (伤害 × 生命窃取%) 点生命

#### 场景:伤害加成
- **当** 战车攻击时
- **那么** 伤害 = 武器基础伤害 × (1 + 百分比伤害%) × (1 + 对应类型伤害%)

#### 场景:攻速加成
- **当** 武器准备攻击
- **那么** 攻击间隔 = 基础间隔 / (1 + 攻速加成%)

#### 场景:暴击判定
- **当** 战车攻击时
- **那么** 暴击概率 = 基础暴击率 + 暴击率属性%

#### 场景:范围影响
- **当** 武器计算射程时
- **那么** 实际射程 = 武器基础射程 + 范围属性

#### 场景:闪避判定
- **当** 敌人攻击战车
- **那么** 闪避概率 = 闪避属性%，判定成功则不受伤害

#### 场景:收获加成
- **当** 战车收集资源
- **那么** 获得资源 = 基础资源 × (1 + 收获属性%)

### 需求:武器槽位系统
战车必须有6个武器槽位，购买武器后自动安装到空闲槽位。

#### 场景:槽位识别
- **当** 游戏启动
- **那么** 系统识别SUV战车的6个Slot节点（Slot_0 到 Slot_5）

#### 场景:武器安装
- **当** 玩家购买武器且有空闲槽位
- **那么** 武器自动安装到第一个空闲槽位

#### 场景:槽位已满
- **当** 玩家购买武器但6个槽位已满
- **那么** 提示"武器槽位已满"，购买失败

### 需求:武器自动瞄准
所有武器必须自动寻找最近敌人并射击。

#### 场景:目标搜索
- **当** 武器处于可攻击状态
- **那么** 武器搜索范围内最近的有效目标

#### 场景:独立射击
- **当** 每把武器的冷却时间结束
- **那么** 该武器独立发射，无需玩家操作

#### 场景:无目标时
- **当** 搜索范围内没有敌人
- **那么** 武器保持待命状态，不发射

### 需求:敌人AI
敌人必须能够追踪玩家并发起攻击。

#### 场景:敌人生成
- **当** 关卡开始
- **那么** 根据波次配置生成怪物

#### 场景:敌人追踪
- **当** 敌人存在且有玩家存活
- **那么** 敌人向最近玩家移动

#### 场景:敌人攻击
- **当** 敌人接近玩家（距离 < 攻击范围）
- **那么** 敌人对玩家造成伤害

### 需求:资源掉落与收集
怪物被击败后必须掉落资源，玩家靠近自动收集。

#### 场景:普通怪掉落
- **当** 怪物（海狸/奶牛）被击败
- **那么** 在击杀位置生成1-3个能量块

#### 场景:Boss掉落
- **当** Boss被击败
- **那么** 在击杀位置生成1个宝箱

#### 场景:资源收集
- **当** 玩家战车靠近能量块或宝箱（距离 < 1.5米）
- **那么** 资源被自动收集，加入玩家货币

### 需求:关卡系统
游戏必须实现60秒关卡时间限制和结算。

#### 场景:关卡计时
- **当** 战斗开始
- **那么** 倒计时从60秒开始

#### 场景:时间结束
- **那么** 弹出关卡结算界面，显示本关表现

#### 场景:关卡通过
- **当** 计时结束且至少1名玩家存活
- **那么** 进入商城界面，可以购买后进入下一关

#### 场景:关卡失败
- **当** 所有玩家战车死亡
- **那么** 进入结算界面，显示本次战斗数据

### 需求:商城系统
玩家可以使用收集的资源购买武器和道具。

#### 场景:商城购买
- **当** 玩家点击武器/道具并有足够货币
- **那么** 扣除货币，武器安装到战车/道具生效

#### 场景:刷新商品
- **当** 玩家点击刷新按钮
- **那么** 商品列表随机刷新，消耗刷新费用

### 需求:抽卡系统
关卡结算和宝箱可以触发抽卡。

#### 场景:结算抽卡
- **当** 关卡结算时
- **那么** 根据玩家表现给予抽取机会

#### 场景:抽卡概率
- **当** 玩家进行抽取
- **那么** 基础概率 N=70%, R=25%, SR=4%, SSR=1%，幸运值额外修正

#### 场景:幸运值影响
- **当** 玩家幸运值 > 0
- **那么** SR概率 + (幸运值 × 1)%，SSR概率 + (幸运值 × 0.5)%

### 需求:存档系统
游戏必须保存和加载玩家进度。

#### 场景:存档保存
- **当** 玩家解锁新内容或完成关卡
- **那么** 自动保存到本地文件

#### 场景:存档加载
- **当** 游戏启动
- **那么** 读取本地存档恢复玩家进度

#### 场景:云同步
- **当** 玩家登录Steam
- **那么** 自动同步本地存档到SteamCloud

### 需求:多人输入
游戏必须支持最多4个手柄同时连接。

#### 场景:手柄识别
- **当** 手柄连接到系统
- **那么** 自动识别为可用输入设备

#### 场景:玩家分配
- **当** 第N个手柄连接（N ≤ 4）
- **那么** 自动分配为Player N-1

#### 场景:手柄断开
- **当** 手柄断开连接
- **那么** 该玩家暂时离场，其他玩家不受影响
