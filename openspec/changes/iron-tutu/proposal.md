## 为什么

市场缺乏类土豆兄弟的战车题材roguelike射击游戏。土豆兄弟验证了"局内roguelike + 局外解锁"的模式在俯视角射击领域的可行性，而战车题材可以将武器系统（6槽位自动安装）做出差异化，同时4人合作模式能填补朋友聚会游戏的需求。

## 变更内容

创建MVP版本的战车roguelike射击游戏，实现完整的"开始界面 → 战斗 → 结算 → 商城 → 下一关"循环。

### 核心功能
- **战车系统**：6槽位车顶武器安装，战车15种数值属性
- **4人合作**：InputSystem多手柄支持，共享视野
- **战斗系统**：战车移动 + 武器自动瞄准射击
- **资源系统**：击杀掉落能量块 → 靠近收集 → 购买武器道具
- **关卡系统**：60秒/关 → 结算 → 商城 → 下一关
- **抽卡系统**：关卡结算属性抽取、商城刷新、宝箱抽取
- **存档系统**：本地JSON + Steam云同步

### MVP内容
- 战车：1辆（基于SUV模型）
- 武器：4种（近战铁球、远程枪械、激光、火焰）
- 怪物：2种小怪 + 1种Boss
- 地图：单场景固定范围

## 功能 (Capabilities)

### 新增功能
- `tank-vehicle`: 战车系统 - 6槽位安装、移动控制、数值属性
- `weapon-system`: 武器系统 - 自动瞄准、多类型武器、合并升级
- `combat-system`: 战斗系统 - 伤害计算、子弹生成、目标锁定
- `enemy-ai`: 敌人AI - 追踪玩家、攻击、掉落资源
- `resource-collection`: 资源收集 - 能量块掉落、靠近触发收集
- `level-system`: 关卡系统 - 60秒倒计时、结算界面、下一关过渡
- `shop-system`: 商城系统 - 武器购买、道具购买、刷新机制
- `gacha-system`: 抽卡系统 - 结算抽卡、宝箱抽取、幸运值影响
- `save-system`: 存档系统 - 本地存储、解锁进度、云同步
- `multiplayer-input`: 多人输入 - InputSystem多手柄识别

### 修改功能
（无）
